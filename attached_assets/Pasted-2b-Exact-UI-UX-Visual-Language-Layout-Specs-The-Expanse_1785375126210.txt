2b. Exact UI/UX Visual Language & Layout Specs (The "Expanse" Look)The frontend styling must closely replicate the high-density layout systems of the Expanse theme. It must look structured, editorial, and commercial. Ensure the layout treats the following components exactly as specified:1. The Header & Multi-Tier Navigation SystemThe Look: Sleek, low-height, fixed (sticky) header with thin, crisp 1px neutral borders. It must feel lightweight despite carrying massive navigation data.Mega Menu Layout: Hovering or clicking a main category must trigger a full-bleed, multi-column mega-menu dropdown. Instead of plain text lists, it must support nested visual category grids with small image thumbnails right next to sub-category text links.Inline Predictive Search Dropdown: When a user clicks the search bar, it must expand to show a multi-pane dropdown before they even finish typing. The left column shows "Trending Searches" and "Suggested Collections," while the right column displays live, image-heavy product matching tiles with prices.2. The Hero Section (The "Editorial Editorial Collage" Engine)The Look: Expanse does not use generic, full-screen slider images that bury content. It relies on a balanced asymmetric layout framework.The Component Spec: Build a responsive hero unit capable of splitting layouts cleanly. For example: a 2/3 width high-resolution video/lifestyle image block paired flush with a 1/3 width editorial product promo block containing a distinct title, clean paragraph typography, and an outlined call-to-action (CTA) button.Typography Overlays: Text overlays on the hero must never block vital parts of the image. Use text boxes with soft, semi-transparent backgrounds or enforce strict left/right content alignment rules with smart text shadow properties.3. Native Promotional Inlines & Ad Tiles ("Shoppable Ads Everywhere")The Look: Advertisement banners must not look like ugly third-party pop-ups. They must blend natively into the catalog grids.The Component Spec: In both the collection grids and search result layouts, implement Polymorphic Promotional Tiles. For every row of 4 regular product cards, the layout engine must be able to swap out 1 or 2 card slots for an editorial lifestyle ad banner (e.g., a "30% off local Kenyan brands" graphic block).Story Banners: Between major scroll blocks on the homepage, implement full-width, low-height editorial section dividers featuring parallax background imagery and subtle, clean text layers.4. The Product Quick-Buy & Mini-Cart DrawersThe Look: Clean, right-aligned slide-out drawers (width: 400px to 450px) using an elegant overlay backdrop blurring the background page (backdrop-filter: blur(4px)).The Component Spec: When clicking "Quick View" or adding an item to the cart, a seamless slide-out drawer appears instantly without full-page reloads. The cart drawer must dynamically feature a visual, tiered progress bar showing how much more the user needs to spend to hit "Free Delivery across Kenya" milestones. Below the checkout button, embed a dedicated carousel for instant, one-click add-to-cart cross-sell items.
